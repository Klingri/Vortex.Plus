about vortex+

Vortex+ is an advanced chrome extension for the web-game Vortex, it includes several quality-of-life and overhauls the base game to the way you like it! It includes several highly compatible mods, examples include: friend updates, dark mode, UI enhancements and custom themes, and so much more!

Owned and developed by Klingri and the development team.
