###### Version 2.6 Pre-Alpha (17.07.2026).

## Why VortexPro Exists

<p>When I joined the Vortex Platform on May 5, 2026, It was underwhelming. The interface was barebones, there was almost no functionality besides friending people, joining maps, browsing, and there was no native dark mode or custom control, which is why I created <a href="https://klingri.github.io/VortexPro/">VortexPro</a> the very same day.</p>

**VortexPro is what Vortex should have been:**

<ul>
    <li>User <i>Control</i> and User <i>Freedom.</i></li>
    <li>More focus on <i>Customization.</i></li>
    <li>
    Plus everything users have been asking for but never got (VortexPro doesn't have everything just yet.)</li>
  </ul>

## Installation

<p>For other methods of Installation, please see VortexPro's <a href="https://github.com/Klingri/VortexPro/blob/stable/.github/INSTALLATION.MD">full Installation guide.</a></p>

### Step-by-Step:
1. **Download:** Go to the [Releases](https://github.com/Klingri/VortexPro/releases) page and download the latest `Source code (zip)`.
2. **Extract:** Unzip the folder to a permanent location on your PC.
3. **Open Extensions Page:**
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Firefox: `about:addons`
   - Brave: `brave://extensions/`
   - Vivaldi: `vivaldi://extensions`
   - Opera/OperaGX: `opera://extensions`
   - Arc: `arc://extensions`
   - Helium: `helium://extensions`
   - Yandex: `browser://extensions`
4. **Developer Mode:** Toggle the **Developer mode** switch in the top right.
5. **Load Unpacked:** Click **"Load unpacked"** and select the folder you just extracted.

## Known Issues & Stability (so far)
<div align="center">
<p>View the full list of Issues <a href="https://github.com/Klingri/VortexPro/blob/stable/.github/ISSUES.md">here.</a></p>
</div>

<ul>
    <li><strong>Performance:</strong> These experimental updates may cause performance issues on lower-end systems.</li>
    <li><strong>UI Glitches:</strong> Minor UI display issues may occur on certain places.</li>
    <li><strong>No native Auto-Updater:</strong> Manual updating, the same way you first downloaded it.</li>
    <li><strong>Compatibility:</strong> VortexPro may be incompatible with Firefox and Firefox-based browsers, VortexPro may or may not be compatible with other extensions made by Klingri.</li>
    <li><strong>Themes:</strong> VortexPro looks best in Dark mode, as that was what it was designed for. I can't guarantee that light mode or other themes look good.</li>
  </ul>

*Submit bugs via [GitHub Issues](https://github.com/Klingri/VortexPro/issues).*
